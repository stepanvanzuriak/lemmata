# core

The data model: SQLite through Drizzle ORM (`drizzle-orm/libsql`), with migrations generated by `drizzle-kit`.

- `src/db/schema.ts`: table definitions. After changing them run `yarn workspace core generate` and commit the new
  folder in `migrations/`.
- `src/db/index.ts`: `openDb(url, migrationsFolder)` opens the database, sets pragmas and applies migrations.
- `src/workspace.ts`: `initWorkspace(dir, migrationsFolder)` creates `<dir>/.lemmata/lemmata.db`.
- `src/<aggregate>.ts`: data functions that take the database first (`createProject(db, input)`).

Tests use an in-memory database: `openDb(":memory:", MIGRATIONS_FOLDER)`.
